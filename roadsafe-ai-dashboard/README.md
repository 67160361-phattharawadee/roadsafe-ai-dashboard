## 🎯 แนวคิดธุรกิจ (Business Concept)
**RoadSafe AI** คือระบบปัญญาประดิษฐ์และคอมพิวเตอร์วิทัศน์ (AI & Computer Vision) ที่ติดตั้งในยานพาหนะ เพื่อตรวจจับพฤติกรรมเสี่ยงของผู้ขับขี่ เช่น อาการง่วงนอน หลับใน หรือการเสียสมาธิ รวมถึงตรวจจับสิ่งกีดขวางบนท้องถนนแบบ Real-time พร้อมระบบแจ้งเตือนเพื่อลดอุบัติเหตุและความสูญเสียในภาคธุรกิจโลจิสติกส์และผู้ใช้รถทั่วไป[cite: 2, 3]

---

## 📊 ฟีเจอร์ของ Storytelling Dashboard
ระบบแดชบอร์ดถูกออกแบบมาเพื่อเล่าเรื่องใน 3 มิติหลัก:
1. **Executive Overview:** สรุปตัวชี้วัดหลัก (KPIs) เช่น จำนวนเที่ยววิ่ง คะแนนความปลอดภัยเฉลี่ย และสถิติการแจ้งเตือนความเหนื่อยล้า
2. **Risk & Trend Analytics:** วิเคราะห์ความสัมพันธ์ระหว่างระยะทางขนส่ง พฤติกรรมการขับขี่ และแยกประเภทพาหนะ (Truck, Public Bus, Delivery Van)
3. **Business Insights:** นำเสนอข้อเสนอแนะเชิงกลยุทธ์เพื่อช่วยผู้บริหารองค์กรโลจิสติกส์ในการลดต้นทุนและเพิ่มประสิทธิภาพความปลอดภัย[cite: 3]

## 🚀 วิธีการรันโปรแกรมในเครื่อง (Local Setup)

หากต้องการจำลองการใช้งานหรือรันระบบแดชบอร์ดในเครื่องคอมพิวเตอร์ สามารถทำตามขั้นตอนด้านล่างนี้ได้เลยครับ:

### ขั้นตอนที่ 1: เปิดโปรแกรม Command Prompt (CMD)
* กดปุ่ม `Windows` บนคีย์บอร์ด พิมพ์คำว่า `cmd` แล้วกด Enter
* ย้ายเข้าไปยังโฟลเดอร์โปรเจกต์โดยใช้คำสั่ง:
  cd Desktop\roadsafe-ai-dashboard

### ขั้นตอนที่ 2: ติดตั้งไลบรารีที่จำเป็น
-   รันคำสั่งผ่าน Command Prompt เพื่อติดตั้งเครื่องมือ Python       ที่ต้องใช้:
    pip install streamlit pandas plotly

### ขั้นตอนที่ 3: สร้างชุดข้อมูล
-   รันสคริปต์เพื่อสร้างชุดข้อมูลสถิติ (1,000 แถว):
    python generate_data.py

### ขั้นตอนที่ 4: รันระบบแอปพลิเคชันแดชบอร์ด
-   เริ่มต้นเปิดใช้งานเว็บแดชบอร์ดด้วยคำสั่ง:
    python -m streamlit run app.py
