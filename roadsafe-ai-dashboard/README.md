## 🎯 แนวคิดธุรกิจ (Business Concept)
**RoadSafe AI** คือระบบปัญญาประดิษฐ์และคอมพิวเตอร์วิทัศน์ (AI & Computer Vision) ที่ติดตั้งในยานพาหนะ เพื่อตรวจจับพฤติกรรมเสี่ยงของผู้ขับขี่ เช่น อาการง่วงนอน หลับใน หรือการเสียสมาธิ รวมถึงตรวจจับสิ่งกีดขวางบนท้องถนนแบบ Real-time พร้อมระบบแจ้งเตือนเพื่อลดอุบัติเหตุและความสูญเสียในภาคธุรกิจโลจิสติกส์และผู้ใช้รถทั่วไป[cite: 2, 3]

## 📁 โครงสร้าง Repository
- `app.py`: โค้ดหลักสำหรับรัน Interactive Storytelling Dashboard (สร้างด้วย Streamlit และ Plotly)
